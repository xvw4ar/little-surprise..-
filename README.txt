LITTLE SURPRISE - WEBSITE FILES

1. Extract this ZIP.
2. Upload index.html, style.css, script.js and README.txt to the root of your GitHub repository.
3. If you have the original song file, keep it in the same folder and name it song.m4a.
   Alternatively, open the page and use ADD YOUR SONG FILE to choose the audio from your device.
4. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

Only the stars and planets are animated. All other visual elements stay still.
The original song audio is not included in this ZIP because it could not be retrieved from the live page.
